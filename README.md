# AI Flutter Study App 📚

An AI-powered Flutter Study App designed to make learning smarter, easier, and more interactive. The application provides students with educational lessons, videos, quizzes, and AI-powered learning assistance.

## 🚀 Features

- 🤖 **AI Assistant:** AI-powered learning assistance.
- 📖 **Lessons:** Access educational lessons and learning materials.
- 🎥 **Video Learning:** Watch educational videos.
- 📝 **Quiz Zone:** Test your knowledge through interactive quizzes.
- 📊 **Progress Tracking:** Track learning progress.
- 🔐 **Authentication:** User login and signup functionality.
- 📱 **User-Friendly Interface:** Simple and interactive design.

## 🛠️ Technologies Used

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Google Gemini AI
- YouTube Integration

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/SarveshYadav-46/AI-Flutter-Study-App.git
```

### 2. Navigate to the Project Folder

```bash
cd AI-Flutter-Study-App
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

```bash
flutter run
```
